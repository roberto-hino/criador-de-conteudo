# Criador Automático de Conteúdo

Sistema profissional para geração automática de apostilas,
e-books e materiais didáticos.

Funcionalidades planejadas:
- Criação automática de conteúdo
- Organização em módulos e capítulos
- Revisão de conteúdo
- Exportação em Word
- Integração futura com o diagramador
